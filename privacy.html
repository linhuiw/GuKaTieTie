隐私政策
版本 1.0  ·  生效日期：2026年3月1日
咕卡贴贴深知个人隐私对您的重要性。本隐私政策说明我们如何收集、使用、存储和保护您的个人信息。在使用本应用前，请您仔细阅读。

一、我们收集的信息

1.1 账户信息

当您使用 Apple ID 登录时，我们会收到：

  • 您的 Apple 用户唯一标识符（User Identifier）
  • 您选择分享的姓名和邮箱地址（由 Apple 决定是否传递）

1.2 用户内容

  • 照片和图像：您通过相机拍摄或从相册选择的照片，用于 AI 贴纸生成
  • 生成的贴纸：AI 处理后生成的贴纸图像，存储于您的设备本地

1.3 使用数据

  • 应用内行为数据：如贴纸生成次数、使用功能等，用于改善服务
  • 崩溃报告：应用异常信息，用于技术问题排查（不含个人身份信息）

1.4 设备信息

设备型号、iOS 版本等技术信息，用于确保应用兼容性。

二、我们如何使用您的信息

用途说明
提供核心服务通过 AI 技术生成和处理贴纸
账户管理维护您的登录状态和账户数据
个性化体验保存您的贴纸收藏和使用偏好
服务改善分析使用数据，优化功能和性能
安全保障检测和防范违规或欺诈行为
客户支持响应您的反馈和问题

三、信息共享

我们不会出售您的个人信息。以下情况下，我们可能与第三方共享信息：

3.1 技术服务商

  • Google（Gemini AI）：您上传的图片将被发送至 Google Gemini API 进行 AI 处理。图片仅用于生成贴纸，不会被 Google 用于模型训练（基于 API 使用条款）
  • Supabase：作为后端基础设施提供商，处理账户数据和 API 请求

3.2 法律要求

当法律法规要求，或为保护我们的合法权益时，我们可能披露必要信息。

四、数据存储与安全

4.1 存储位置

  • 本地存储：贴纸图片和收藏数据存储在您的设备本地，不上传至云端
  • 服务器存储：账户信息存储于 Supabase 服务器

4.2 数据安全

  • 数据传输使用 HTTPS 加密
  • 图片处理完成后，我们不在服务器长期保存您的原始照片
  • 我们采用行业标准的安全措施保护您的数据

4.3 数据保留

  • 账户数据在您主动删除账户前持续保存
  • 临时处理的图像数据在生成完成后立即删除

五、您的权利

  • 访问权：查看我们持有的您的个人信息
  • 更正权：要求更正不准确的信息
  • 删除权：要求删除您的账户及相关数据
  • 数据可携权：获取您的数据副本

如需行使上述权利，请通过应用内「意见反馈」或邮件联系我们。

六、权限说明

权限用途是否可拒绝
相机拍摄照片用于生成贴纸可拒绝（将无法使用拍照功能）
相册读取从相册选择图片可拒绝（将无法从相册导入）
相册写入将生成的贴纸保存到相册可拒绝（将无法保存到相册）

七、儿童隐私

本应用不针对 13 岁以下儿童。如果我们发现意外收集了儿童个人信息，将立即删除。如果您认为我们可能收集了您孩子的信息，请联系我们。

八、跨境数据传输

由于我们使用的技术服务商（Google、Supabase）位于境外，您的部分数据可能会被传输至中国大陆以外的地区处理。我们确保此类传输符合适用法律法规的要求。

九、隐私政策更新

我们可能定期更新本隐私政策。重大变更时，我们将通过应用内通知告知您。更新后的政策自发布之日起生效。

十、联系我们

如对本隐私政策有任何疑问，请联系：

  • 应用内反馈：在「我的」页面点击「意见反馈」
  • 电子邮件：privacy@guka.app
